# Video to Guide

把一段软件操作录屏，自动变成一份**能照着做的图文手册**：每一步都有截图、时间戳和操作说明。

看教程时反复暂停记步骤、截图和说明对不上、回头想找「那个操作是在第几分钟」——这些事它替你做。

## 你会得到什么

一份本地打开的 HTML 手册：左边是步骤列表，右边是该步骤的截图和时间，**点时间能跳回视频对应位置**。同时导出 Markdown，方便贴进 Wiki、Notion 或自己的笔记。

每一条步骤都必须挂着证据——要么是视频里那句话，要么是那一帧截图。没有证据的步骤不会进手册。

## 怎么用

1. **解压便携包**，双击 `VideoToGuide.exe`（不需要装 Python，也不需要装 FFmpeg）
2. **配一个模型服务**：本机跑 LM Studio / Ollama / llama.cpp 任选其一，或者在设置里填云端 API Key
3. **拖进视频，点「开始分析」**，等它跑完，就能看手册、改步骤、导出

首次配置模型服务：右上角 **设置…** → 服务商选「本机服务（免费 · OpenAI 兼容）」→ 填你服务的端口 → 点 **获取模型** → 分别选视觉模型和步骤模型 → 保存。

命令行也有一套：

```bash
vtg doctor                        # 检查环境（软件环境 / AI 服务分开看）
vtg analyze "D:/录屏/我的教程.mp4"  # 直接分析
vtg gui                           # 打开桌面界面
```

## 功能

| 能力 | 说明 |
|---|---|
| 语音转文字 | 内置 faster-whisper，small 模型随包分发；想更准可在设置里下载 large-v3 |
| 关键帧抽取 | 按「画面变化 + 讲解密度」选帧，画面静止时不会抽出成堆废图 |
| 画面理解 | 任一 OpenAI 兼容的视觉模型（本机免费或云端） |
| 步骤整理 | 把字幕和画面描述合成有序步骤，每步带时间、截图、依据 |
| 人工修改 | 界面里改标题、操作、预期结果，改完重新导出 |
| 导出 | HTML（可跳转视频时间）+ Markdown |
| 历史复用 | 再打开不重新跑模型，重导出不花钱 |

## 已知限制

- **步骤粒度不完全可复现**：同一段视频跑两次，步骤数可能不一样。重新分析前会提示，并默认保留已有结果。
- **现实场景（做饭、手工、装配）仍是 Beta**：会漏关键动作，生成的手册需要对着原视频核对，不要当作安全关键操作的唯一依据。
- **同一窗口里的多个操作，时间可能重叠**：单帧画面分不清「先改主题还是先勾自动保存」。
- 需要事先准备一个模型服务，软件本身不带模型（语音模型除外）。

## 系统要求

Windows 10/11 x64。有一块 NVIDIA 显卡会快很多，没有也能跑（用 CPU）。

## 关于隐私

视频只在你的机器上处理，不会上传。模型服务如果选本机的，全程断网也能用。
